# To Do Board App [Still developing...]

## 1. Application

 ![Screenshot 2025-02-14 at 1 17 28 PM](https://github.com/user-attachments/assets/7ad1fa11-25f6-42cb-abbe-dfbbce59ccfa)

Here is a simple to do board application. 

You can type a request like "create a new note, call it costco, write vegi,eggs,milk"

or a series of requests [ "I want to create a note", "call it costco", "write vegi, eggs, milk"]

You can do requests related "Create / Delete / Find / Change Status"


[Watch the video](https://github.com/YoonjungChoi/Project_GenerativeAI/blob/main/project4_ToDoBoardApp/Demo_.mp4)


## 2. Setup

**Installation**
1. Clone this repository to your local machine:
```
git clone https://github.com/YoonjungChoi/Project_GenerativeAI
```
2. Navigate to the project directory
```
cd project4_ToDoBoardApp
```
3. install streamlit or any other needed libs.
```
pip install streamlit
```
4. create .env file and add your NVIDIA_API_KEY
```
NVIDIA_API_KEY=your-key-here
```
**Running the Application**

1. type this command
```
  streamlit run app.py
```
